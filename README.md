# NoteFlow — Менеджер заметок

Легковесный локальный менеджер заметок с графическим интерфейсом, разработанный на Python и PyQt6.

## Технологии
* Python 3.10+
* PyQt6 (GUI)
* SQLite (База данных)
* Архитектура: MVC (Model-View-Controller)
